# 验证范围

测试设备为 Redmi K70 Pro，Android 16 / HyperOS 3，KernelSU，LSPosed 2.0.2 (7668)。以下为该设备的实测结果，不能推导为对其他 ROM 或硬件的兼容保证。

## 地址切换

- 在 Wi-Fi 7 MLO 网络请求更改设备地址；HAL 返回接受，系统真实读回与 wlan0 一致。
- 驱动生成独立链路地址；设备地址和链路地址分别显示。
- 更改后手机通过 Wi-Fi ping 网关成功，电脑 ARP 邻居表独立确认新地址。
- 恢复系统策略后读回原系统地址，路由器页面显示恢复后的地址。
- 完成改址、恢复及再次改址，过程中没有重启手机。

## 详情与外观

- 实测读取 Wi-Fi 7 标准、5 GHz 频段、信道、WPA3-SAE、局域网 IPv4 与子网掩码。
- 授予精确位置权限后获取真实 BSSID。
- IPv4 出口查询通过 IPIP 备用服务返回；测试网络中前两个服务不可用。IPv6 查询未成功，界面显示失败原因。
- 检查三个页面的深色显示；切换主题保留未提交输入。
- 强制停止并重新打开后，主题偏好仍保存。
- 未实测系统定时夜间切换；未验证所有 MLO 多链路组合和长期漫游。

## 构建与规则

- Android SDK 36 / Build Tools 36.0.0 / JDK 17 编译成功，APK v3 签名校验通过。
- `RulesTest` 覆盖非法输入、5000 个随机地址，以及主接口/网络配置隔离。
- 0.6.0 APK SHA256：`67933086AF3E1AC902A2F113B52DD5B1A807848883EAA9449B40D054BE507AFB`。
